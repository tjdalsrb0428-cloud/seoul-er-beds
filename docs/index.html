      계산 방법 (수업 개념)
      • 도착 시 병상 Ai ~ Bernoulli(pi): 수집 데이터에서 병원·시간대별로 병상이 있었던 비율. 관측이 적으면 라플라스 보정(베이즈 추정)으로 전체 평균 쪽으로 당김.
      • 실시간 반영 = 조건부확률: 지금 '병상 있음/만실'일 때 Δ분 뒤 도착하면 병상이 있을 확률 P[A(t+Δ)=1 | A(t)].
      • E[T] = Σk P[N ≥ k]·Dk + 확인시간 × Σk P[N > k],   P[N ≥ k] = Πj<k(1 − pj)
      • N의 분포: P[N = n] = Πj<n(1 − pj) · pn (병원마다 p가 다른 Geometric의 일반화). 병원 간 독립을 가정하므로, 동시에 붐비는 실제 상황에서는 더 나쁠 수 있음.
      • 기다리기 vs 옮기기: 만실 지속시간 W ~ Exponential이면 무기억성에 의해 남은 대기시간 기댓값 = E[W].
